This is our first step. Learn OpenCV first, then YOLO detection, then Tracking (ByteTrack), then OCR for number plate.
What is OpenCV and why we need it?
OpenCV is our eyes of the project. It is a library that helps computer to read image, video and webcam. YOLO detects objects but YOLO does NOT open camera or draw on screen. That work is done by OpenCV.
So in whole project OpenCV job is simple - take input (photo/video/webcam), give us the frame, we draw boxes and text on it, then show it on window. Thats all we need from OpenCV for now.

First tell me how to open a photo?
Simplest input is a image. Read it, show it, wait for key, then close window.
import cv2 as cv

frame = cv.imread("image.jpg") # frame is a numpy array (H x W x 3, BGR)

cv.imshow("My Photo", frame) # open a window named "My Photo" and show frame
cv.waitKey(0) # 0 means wait forever till any key pressed
cv.destroyAllWindows() # close all windows
Here frame is not a normal picture, it is a numpy array of numbers. Each pixel has 3 values Blue Green Red (BGR not RGB, remember this OpenCV is BGR).
What is this H x W x 3 thing?
Every frame in OpenCV is just a grid of numbers. Shape means how big that grid is.
Part Meaning Example
H Height (number of rows / pixels top to bottom) 480
W Width (number of columns / pixels left to right) 640
3 3 color channels (Blue, Green, Red) BGR

print(frame.shape) # output like (480, 640, 3) -> height, width, channels

This is important because when YOLO gives us box points (x1,y1,x2,y2), they are pixel positions on this same grid.
Now how to open webcam or a video?
Photo is one frame only. Video and webcam is many frames coming one by one. So we use a loop to read them continuously.
import cv2 as cv

cap = cv.VideoCapture(0) # 0 = default webcam. for video file put "video.mp4"

while True:
    ret, frame = cap.read() # ret = True/False (did we get a frame?), frame = the image
    if not ret: # if no frame (camera off or video ended) then stop
        break

    cv.imshow("Live Feed", frame) # show current frame

    if cv.waitKey(1) & 0xFF == ord('q'): # wait 1ms, if 'q' pressed then stop
        break

cap.release() # free the camera
cv.destroyAllWindows() # close windows
This loop is the heart of full project. Every frame we will pass to YOLO, get boxes, draw them, show. Right now we only show plain frame.
Tell me what these VideoCapture number/name means?
Same VideoCapture function but input decide what it reads. This is very useful for us because our project is MULTI CAMERA vehicle tracking.
Input What it opens Use case
cv.VideoCapture(0) Default webcam Testing on laptop
cv.VideoCapture(1) Second camera (USB cam) Multi camera setup
cv.VideoCapture("clip.mp4") Video file from disk Testing on recorded footage
cv.VideoCapture("rtsp://...") IP / CCTV camera stream Real deployment (traffic cam)
For our multi camera project each camera is just one VideoCapture. So one camera = one cap object. Keep this in mind.
Now the main part - how to draw a bounding box?
Here green color is our box. YOLO will later give us x1,y1,x2,y2 points but for now we put them by hand to learn.
A box needs 2 corner points -> top-left (x1,y1) and bottom-right (x2,y2).
import cv2 as cv

frame = cv.imread("car.jpg")

# suppose these points came from YOLO later
x1, y1 = 100, 80   # top-left corner
x2, y2 = 300, 250  # bottom-right corner

# draw rectangle: (frame, corner1, corner2, color BGR, thickness)
cv.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)

# write text above the box: (frame, text, position, font, size, color, thickness)
cv.putText(frame, "Car", (x1, y1 - 10), cv.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)

cv.imshow("Box Demo", frame)
cv.waitKey(0)
cv.destroyAllWindows()
Remember color is (Blue, Green, Red). So (0,255,0) is pure green. (0,0,255) is red. (255,0,0) is blue.
Explain rectangle and putText properly?
These 2 functions we will use most. Learn each part.
cv.rectangle(frame, (x1,y1), (x2,y2), color, thickness)
Part Meaning
frame the image we draw on
(x1, y1) top-left corner point
(x2, y2) bottom-right corner point
color BGR color of box line
thickness line thickness in pixels (-1 = fill full box)

cv.putText(frame, text, (x,y), font, scale, color, thickness)
Part Meaning
text what to write (like "Car" or id number)
(x, y) bottom-left point where text starts
font cv.FONT_HERSHEY_SIMPLEX (standard one)
scale size of text (0.6 is good)
color / thickness same as rectangle
Some other small things I should know?
Yes few extra OpenCV things that come useful in our project.
# resize a frame (useful when camera frame is too big/slow)
frame = cv.resize(frame, (640, 480)) # (width, height)

# convert color BGR to grey (some steps need grey image)
grey = cv.cvtColor(frame, cv.COLOR_BGR2GRAY)

# crop a part of frame (this is how we cut number plate for OCR later)
crop = frame[y1:y2, x1:x2] # numpy slicing -> rows first, then columns

# save a frame as image file
cv.imwrite("saved.jpg", frame)

# draw a dot / circle (we can use this for the point on holograph map)
cv.circle(frame, (cx, cy), 5, (0, 0, 255), -1) # center, radius, color, -1 = filled

# draw a line
cv.line(frame, (x1, y1), (x2, y2), (255, 0, 0), 2)
That crop = frame[y1:y2, x1:x2] line is very important. When we detect a vehicle later, we cut only that box area and send to OCR to read the number plate.
Give me one small full program to test everything?
Run this. It opens webcam, draws one fixed box and text on every frame, and shows live. Press q to quit. If this runs then your OpenCV is ready.
import cv2 as cv
import numpy as np

cap = cv.VideoCapture(0) # open webcam

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # draw a test box and text (later YOLO will give real points)
    cv.rectangle(frame, (100, 100), (300, 300), (0, 255, 0), 2)
    cv.putText(frame, "Test Box", (100, 90), cv.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 0), 2)

    cv.imshow("OpenCV Test", frame)

    if cv.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv.destroyAllWindows()
There is nothing more we need from OpenCV right now for our project. Important facts to remember are following
- OpenCV is only for input and drawing. Detection is YOLO's job, tracking is ByteTrack's job, reading plate is OCR's job. OpenCV just handles camera and drawing on screen.
- OpenCV uses BGR order not RGB. So color (0,255,0) is green, (0,0,255) is red. Dont get confused.
- frame is a numpy array (Height x Width x 3). Box points x1,y1,x2,y2 are pixel positions on this array.
- The while loop (cap.read -> draw -> imshow -> waitKey) is the main loop of full project. We only add YOLO and tracking inside it later.
- crop = frame[y1:y2, x1:x2] is how we cut a detected object to send for number plate OCR.
- For our multi camera project, each camera is one VideoCapture object. One camera = one cap.
- Always release the camera (cap.release) and destroy windows at end, otherwise camera stays busy.
