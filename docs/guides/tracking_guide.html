Step 3 - Tracking. You know OpenCV (input+draw) and YOLO (detect). Now Tracking gives each object a fixed ID so we can follow the SAME car frame after frame. After this comes OCR (number plate). This guide is single camera only.
Why do we even need tracking? YOLO already detects.
Because YOLO has NO memory. Every frame YOLO looks fresh and gives new boxes. It does not know the car in frame 2 is the same car from frame 1. To YOLO every frame is a brand new world.
For our project we must FOLLOW a vehicle - count it, track its path, read its plate once, not again and again. For that each vehicle needs a fixed ID that stays same while it is on screen. Giving that stable ID is the tracker's only job.
Only YOLO YOLO + Tracker
Box appears, but no name/number Box appears with a fixed ID (e.g. ID 7)
Same car looks new every frame Same car keeps ID 7 across frames
Cant count or follow Can count, follow path, read plate once
How does a tracker keep the same ID? What is the logic?
Very simple idea. Tracker looks at last frame's boxes and this frame's new boxes, and tries to MATCH them - "which new box is the same object as which old box?". If matched, it keeps the old ID. If a box matches nothing, it is a new object and gets a new ID.
To match, tracker uses two clues:
Clue Meaning Simple word
Motion It predicts where the old box should move next (a car moving right will be a bit more right). Then matches by overlap. (This predictor is called a Kalman filter.) "where should it be?"
Appearance (Re-ID) It remembers what the object looks like (a color/shape fingerprint) and matches by looks. Helps when two cars cross each other. "what does it look like?"
Motion is fast and cheap. Appearance is heavier but saves us when objects cross or hide for a moment. Good trackers use both.
There are many trackers - ByteTrack, DeepSORT etc. Which one for us?
Here is the short compare. Only the first two matter for us because they come built-in inside YOLO (ultralytics), no extra library.
Tracker Uses Speed Built in YOLO?
ByteTrack Motion only (fast, also keeps low-confidence boxes so nothing drops) ⚡ Fastest ✅ Yes
BoT-SORT Motion + camera-shake fix + appearance Re-ID Fast ✅ Yes
DeepSORT Motion + appearance (older classic) Slower ❌ No (extra lib)
OC-SORT / StrongSORT Improved versions, heavier setup Varies ❌ No
Our choice: BoT-SORT (main) and ByteTrack (fast fallback).
Why BoT-SORT for us:
- It is BoT-SORT = ByteTrack PLUS two extra things: camera-shake fix (great for CCTV / traffic cams that shake or pan) and appearance Re-ID (holds the right ID when two vehicles cross).
- Both BoT-SORT and ByteTrack are ONE line in YOLO, same library we already use. Zero new install.
- Use ByteTrack when the pc is weak or we need max FPS (it skips the appearance part so it is lighter).
Ok show me the code. How to turn on tracking?
Big point - we do NOT write the tracker ourselves. YOLO has it inside. We only change model(frame) to model.track(frame, ...). Thats the whole switch.
import cv2 as cv
from ultralytics import YOLO

model = YOLO("yolo11l.pt")

frame = cv.imread("cars.jpg")

# .track() instead of normal call. it gives boxes + an ID for each
results = model.track(frame, persist=True, tracker="botsort.yaml")
Part Meaning
model.track(...) run detection + tracking together
persist=True remember IDs from the last frame (very important for video, else IDs reset each frame)
tracker="botsort.yaml" use BoT-SORT. for the fast one put "bytetrack.yaml"
And where is the ID? How to read it?
Same box as before (box.xyxy, box.cls, box.conf) but now it also has box.id - the fixed track ID. We read it and draw it on the frame.
for r in results:
    for box in r.boxes:
        # sometimes id is empty on first sight, so check
        if box.id is None:
            continue

        track_id = int(box.id[0])              # the fixed ID, like 7
        x1, y1, x2, y2 = map(int, box.xyxy[0]) # box points
        cls = int(box.cls[0])
        name = model.names[cls]

        # draw box + show name and ID
        cv.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
        cv.putText(frame, f"{name} ID:{track_id}", (x1, y1 - 10),
                   cv.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)
Thats it. Now the same car shows "car ID:7" and it keeps ID 7 as long as it stays on screen. Thats tracking working.
Note: box.id can be None for a box YOLO just saw but tracker has not confirmed yet. Always check "if box.id is None: continue" or code will crash.
Now full webcam version like real project?
This is our YOLO webcam loop, just model() changed to model.track(). This is basically our single-camera project skeleton.
import cv2 as cv
from ultralytics import YOLO

model = YOLO("yolo11l.pt")
cap = cv.VideoCapture(0) # webcam. put "traffic.mp4" for a video

vehicles = [2, 3, 5, 7] # car, motorcycle, bus, truck

while True:
    ret, frame = cap.read()
    if not ret:
        break

    results = model.track(frame, persist=True, tracker="botsort.yaml", stream=True)

    for r in results:
        for box in r.boxes:
            if box.id is None:
                continue
            cls = int(box.cls[0])
            if cls not in vehicles: # only vehicles
                continue

            track_id = int(box.id[0])
            x1, y1, x2, y2 = map(int, box.xyxy[0])
            name = model.names[cls]
            cv.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv.putText(frame, f"{name} ID:{track_id}", (x1, y1 - 10),
                       cv.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)

    cv.imshow("YOLO + BoT-SORT Tracking", frame)
    if cv.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv.destroyAllWindows()
Run this on a traffic video. You will see each vehicle keep its own ID number while moving. That fixed ID is what lets us count vehicles and later read each plate only once.
There is nothing more we need about tracking right now. Important facts to remember are following
- YOLO has no memory. Tracker's only job is to give each object a fixed ID that stays same across frames.
- Tracker matches old boxes to new boxes using Motion (where it should move - Kalman) and Appearance (what it looks like - Re-ID).
- We do NOT build the tracker. YOLO has it inside. Just use model.track() instead of model().
- persist=True is a MUST for video, it carries IDs from last frame. Without it IDs reset every frame.
- tracker="botsort.yaml" for BoT-SORT (our main), "bytetrack.yaml" for the faster ByteTrack.
- The ID is box.id. Always check "if box.id is None: continue" before using it.
- BoT-SORT = ByteTrack + camera-shake fix + appearance, so it holds IDs better when vehicles cross. Use ByteTrack if pc is slow.
- This is SINGLE camera tracking. IDs are stable within one camera feed.
