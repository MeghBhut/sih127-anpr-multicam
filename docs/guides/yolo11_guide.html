YOLO: YOLO will give us the real box points. After this comes Tracking then OCR. This only covers Object detection.
What is YOLO in simple words?
YOLO means You Only Look Once. It looks at one frame one time and tells us what objects are in it and where they are. Thats it.
OpenCV gives us the frame, YOLO looks at the frame and says "there is a car here, a person there". It gives us box points and object name. (We will cover exact YOLO Mechanism in future.)
We are using YOLO11 here, latest and stable version from ultralytics. Same team as before just newer and better.

What is basic commands and what they do?

from ultralytics import YOLO # to bring YOLO in our code

model = YOLO("yolo11l.pt") # load pre-trained model (trained on COCO). It alrady has trained model on thousands of images.

That yolo11l.pt file downloads automatic first time. 11 is version, l is size (large). Different letter means different size and speed.
Model Name / size Speed Accuracy Use case
yolo11n Nano ⚡ Fastest ❌ Lowest Edge devices, CPU, real-time
yolo11s Small Fast Good Laptops, entry GPUs
yolo11m Medium Balanced Better Most real projects
yolo11l Large Slower High Powerful GPUs
yolo11x Very large Slowest Best Max accuracy
For learning you can use yolo11n (fast, works on any laptop). For accuracy we use yolo11l. Start with n if your pc feels slow on large.
What is this COCO thing everyone says?
COCO is a big ready dataset. The model is already trained on it, so it already knows 80 common objects. We dont train anything, we just use it.
Each object has a class id number. YOLO gives us this number, we check which object it is. Some useful ones for us:
Class ID Object
0 person
2 car
3 motorcycle
5 bus
7 truck
47 apple
So for our vehicle project we mostly care about 2,3,5,7 (car, motorcycle, bus, truck). apple 47 is just for testing fun. We dont have to remember all 80, model already knows them.
Now show me how to detect objects in a photo?
Simplest test. Load model, give a image, YOLO returns results, we read the boxes. Here green color is our drawing.
import cv2 as cv
from ultralytics import YOLO

model = YOLO("yolo11l.pt") # load pre-trained model

frame = cv.imread("cars.jpg") # our input photo

results = model(frame) # YOLO looks at the frame, returns results

for r in results: # results is a list, we go through it
    for box in r.boxes: # r.boxes = all objects found in the frame
        x1, y1, x2, y2 = map(int, box.xyxy[0]) # box corner points, made integer
        cls = int(box.cls[0]) # class id number (0=person, 2=car ...)
        conf = float(box.conf[0]) # confidence, how sure model is (0 to 1)
        name = model.names[cls] # turn id number into name text like "car"

        # draw box and write name on frame (this is OpenCV work)
        cv.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
        cv.putText(frame, f"{name} {conf:.2f}", (x1, y1 - 10), cv.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)

cv.imshow("YOLO Detection", frame)
cv.waitKey(0)
cv.destroyAllWindows()
This is the MAIN thing to learn. Box points + class name + draw. Everything else in project is built on top of this.
Explain that box.xyxy, box.cls, box.conf clearly?
For every object YOLO found, it gives us these 3 things. Learn each one.
Code What it gives Example
box.xyxy[0] 4 corner points x1,y1,x2,y2 (where the box is) (100, 80, 300, 250)
box.cls[0] class id number (which object) 2 (car)
box.conf[0] confidence 0 to 1 (how sure model is) 0.91
model.names[cls] turns id number into name text "car"
We do map(int, ...) on the points because OpenCV needs whole numbers not decimals to draw. And conf:.2f just means show 2 digits after point like 0.91.
I only want vehicles not everything, how to filter?
Easy. Just check the class id before drawing. If it is a vehicle then draw, else skip.
vehicles = [2, 3, 5, 7] # car, motorcycle, bus, truck

for r in results:
    for box in r.boxes:
        cls = int(box.cls[0])
        if cls in vehicles: # only if it is a vehicle
            x1, y1, x2, y2 = map(int, box.xyxy[0])
            conf = float(box.conf[0])
            name = model.names[cls]
            cv.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv.putText(frame, f"{name} {conf:.2f}", (x1, y1 - 10), cv.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)
Same for person only use [0], for apple use [47]. This filter is how we control what to detect.
Now full webcam version like real project?
This is OpenCV camera loop from step 1 + YOLO inside it. Every frame goes to YOLO. Press q to quit. This is basically our project skeleton (without tracker).
import cv2 as cv
from ultralytics import YOLO

model = YOLO("yolo11l.pt")
cap = cv.VideoCapture(0) # webcam. put "video.mp4" for a file

while True:
    ret, frame = cap.read()
    if not ret:
        break

    results = model(frame, stream=True) # stream=True is better for video/webcam

    for r in results:
        for box in r.boxes:
            cls = int(box.cls[0])
            x1, y1, x2, y2 = map(int, box.xyxy[0])
            conf = float(box.conf[0])
            name = model.names[cls]
            cv.rectangle(frame, (x1, y1), (x2, y2), (0, 255, 0), 2)
            cv.putText(frame, f"{name} {conf:.2f}", (x1, y1 - 10), cv.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 0), 2)

    cv.imshow("YOLO11 Live", frame)
    if cv.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv.destroyAllWindows()
Notice for webcam/video we add stream=True. It makes YOLO handle frames one by one smoothly. For single photo we dont need it.
Important facts to remember are following
- YOLO does NOT return a picture. It returns predictions (box points, class id, confidence). We draw them ourselves with OpenCV.
- YOLO11 is pre-trained on COCO so it already knows 80 objects. We are NOT training anything, just using it.
- We only need box.xyxy (points), box.cls (which object), box.conf (how sure). Thats the whole answer.
- model.names[cls] turns the number into a name text like "car" or "person".
- To detect only what we want, filter by class id (2,3,5,7 for vehicles).
- Confidence tells how sure model is. Low confidence = more boxes but more wrong ones.
- YOLO runs on CPU by default, becomes much faster on GPU (CUDA). For learning CPU is fine, use yolo11n if slow.
- Right now every frame YOLO sees is fresh, it does NOT remember same car across frames. That memory part is TRACKING, our next guide.
